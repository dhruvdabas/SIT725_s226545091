# 1.1P – Introduction to Programming and Git

Week 1 workshop activities for SIT725 Applied Software Engineering.

## Contents

- `index.js` – introductory JavaScript program covering variables, functions, conditionals, loops, arrays, objects, a small calculator and `reduce`.
- `screenshots/` – evidence of Git commands, commits, pushes and the program running.

## Run

```bash
node index.js
```
